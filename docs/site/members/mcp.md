# MCP server

Use Standwise from any AI client that speaks the Model Context Protocol: Claude Desktop, Cursor, Codex, VS Code and others. Your agent drafts your daily with you and sends it only after you confirm. If you manage a team, it can also read your team's digests, dailies and blockers.

Before you configure a client, [install the CLI and sign in](/members/getting-started). Claude Code users get this server through the [plugin](/members/claude-code).
